

# Spam Detection Using Machine Learning 📚

## Project Overview
This project aims to classify SMS messages as **Spam** or **Ham** using various machine learning algorithms like Naive Bayes, Logistic Regression, Random Forest, and Support Vector Machine (SVM).

## How to Run the Code 🚀
1. **Clone or Download the Repository**.
2. **Place the `Spam Detection.csv` dataset** in the working directory.
3. **Install Required Libraries**:
   ```bash
   pip install pandas scikit-learn
   ```
4. **Run the script** in your preferred environment (Python script, Jupyter Notebook, Google Colab).

## Dependencies 📦
- Python 3.x
- pandas
- scikit-learn

## Input Details 📥
- Dataset: `Spam Detection.csv`
- Columns:
  - `Message`: Text message content
  - `Category`: Label ('ham' for non-spam, 'spam' for spam)

## Output Details 📤
- Model training outputs:
  - Accuracy scores
  - Classification reports (Precision, Recall, F1-score)

## Project Structure 🏗️
- Data Cleaning & Preprocessing
- Feature Extraction (TF-IDF Vectorization)
- Model Training (Naive Bayes, Logistic Regression, Random Forest, SVM)
- Model Evaluation
- Results Interpretation

## Configuration/Environment Setup ⚙️
- No GPU required.
- Works smoothly on laptops/desktops with minimal setup.
- Recommended platforms: Jupyter Notebook, Google Colab, or any Python IDE.

## Notes 📌
- SVM model achieved the best performance.
- Future work includes testing deep learning techniques.
